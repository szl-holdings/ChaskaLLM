# Contributing

**Control before action. Evidence after.**

1. **Control before action.** State the invariant first (failing test or written assertion), then change behavior.
2. **Evidence after.** Update receipts: CI, smoke, or explicit `UNAVAILABLE` / `NOT_CLAIMED` when unmeasured.
3. **Canonical surfaces.** Product https://a-11-oy.com · Proof https://a11oy.net. Soft Shield mouth branding stays Stephen-facing SZL Holdings — never AlloyScape-hero on this surface.

## Branch model

- Branch from default as `szl/<change>` or `rosa/<change>`.
- One concern per PR; Conventional Commits (`feat:`, `fix:`, `docs:`, `test:`, `chore:`, `ci:`).
- Land via pull request only — no direct pushes to default.

## Tests

Run the repo test suite before opening a PR. Prefer MEASURED smoke over aspirational claims.
